# Ideas

This repo is a lightweight collection of project ideas and high‑level plans. Each folder contains a focused concept with enough structure to pick up and build.

Use this as a staging ground for exploration—when an idea matures, it can move to its own dedicated repo.

## Table of Contents

- **tauri-gentle-desktop-app-v1** — Desktop podcast editor MVP using Tauri 2 + Gentle for alignment
  - **Status:** Ideation
  - **Date started:** 2026-02-22

- **twitter-engagement-analysis** — Identifies the top 20 accounts a user most interacts with, fetches their highest-engagement tweets, and uses Claude to extract actionable engagement patterns
  - **Status:** Prototype built — implementation plan in `twitter-engagement-analysis/plan.md`
  - **Date started:** 2026-02-23

- **photos-only-social-network** – A social media mobile app where users can only upload photos, not videos. No reels. Very simple and open source algorithm. No ads. You pay 10 USD per year to access it and help maintain it accessible and online.
  - **Status:** Idea  — implementation plan in `photos-only-app/research.md`
  - **Date ideated:** 2026-02-25
