# Repository boundary

- Keep this folder focused on custom TTS training, fine-tuning/LoRA, datasets,
  codecs and non-speech/animal-sound synthesis research.
- Voice-agent LLM selection, Qwen/Nanbeige benchmarks, results, timing evidence,
  plots and reproduction scripts belong in `gianpaj/local-voice-agent/benchmarks`.
  Link to that archive instead of adding duplicate data or charts here.
- The existing `benchmarks/companion-support-2026-11-07/` Markdown files and
  benchmark-selection note are redirects for old links, not experiment homes.
- Preserve the distinction between research proposals and completed training
  or measured synthesis results; do not infer TTS capabilities from LLM scores.
